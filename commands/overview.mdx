JAVLI is a Python-based command-line Minecraft launcher that brings together modern and historical Minecraft versions, Microsoft account management, Java runtime installation, isolated game instances, modloaders, mods, modpacks, resource packs, shaders, and local server management under a single `javli` command. This page lists every top-level command available in JAVLI and links to the detailed reference page for each group.

## All commands at a glance

| Command | Description |
|---|---|
| `javli release <version>` | Launch a Minecraft release build |
| `javli snapshot <version>` | Launch a Minecraft snapshot build |
| `javli beta <version>` | Launch a Beta-era build |
| `javli alpha <version>` | Launch an Alpha-era build |
| `javli infdev <version>` | Launch an Infdev-era build |
| `javli indev <version>` | Launch an Indev-era build |
| `javli classic <version>` | Launch a Classic-era build |
| `javli preclassic <version>` | Launch a Pre-Classic build |
| `javli random` | Launch a randomly selected Minecraft version |
| `javli login` | Authenticate with a Microsoft account |
| `javli account` | Manage saved Microsoft accounts |
| `javli java` | Install and manage Java runtimes |
| `javli instance` | Manage isolated Minecraft instances |
| `javli mods` | Search, install, and remove mods via Modrinth |
| `javli modpack` | Search and install modpacks via Modrinth |
| `javli loader` | Install a standalone modloader for a Minecraft version |
| `javli resourcepack` | Search, install, and remove resource packs via Modrinth |
| `javli shader` | Search, install, and remove shaders via Modrinth |
| `javli server` | Create and manage local Minecraft servers |
| `javli versions` | List available Minecraft versions |
| `javli search <query>` | Search versions by ID or keyword |
| `javli info <version>` | Show detailed metadata for a specific version |
| `javli stats` | Show version count statistics by source and era |
| `javli update` | Update the JAVLI binary from GitHub Releases |

## Data directory

All JAVLI data lives under `~/.mcli/`:

```text
accounts.json
assets/
cache/
instances/
libraries/
loaders/
runtimes/
servers/
versions/
```

<Warning>
  `accounts.json` may contain Microsoft authentication refresh tokens. Treat it as a sensitive file and avoid sharing it.
</Warning>

## Sources

JAVLI pulls version metadata from two sources, selectable with `--source` on most commands:

| Source | Description |
|---|---|
| `mojang` | Official Mojang version manifest — releases, snapshots, and legacy eras |
| `omniarchive` | Direct historical Java client discovery for preserved Minecraft builds |
| `auto` | Try both sources and merge results (default) |
