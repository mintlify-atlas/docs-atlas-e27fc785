JAVLI is a command-line launcher for Minecraft Java Edition. It handles everything from downloading game versions and managing Java runtimes to installing modloaders, syncing mods from Modrinth, and running local servers — all from your terminal, with no GUI required.

## What JAVLI Does

JAVLI brings the full Minecraft lifecycle under one command. You can launch any version from modern releases back to pre-classic builds, manage multiple Microsoft accounts, and keep Java runtimes up to date automatically.

## Quick Example

```bash
# Install and log in
pip install javli-minecraft
javli login

# Launch the latest release
javli release 1.21.1

# Launch with Fabric
javli release 1.21.1 --fabric

# Create an isolated instance
javli instance create survival release 1.21.1
javli instance launch survival
```

<Steps>
  <Step title="Install JAVLI">
    Download a prebuilt binary from GitHub Releases, or install from source with `pip install javli-minecraft`.
  </Step>
  <Step title="Log in with Microsoft">
    Run `javli login`. JAVLI opens a device-code URL in your browser — enter the code to authenticate your Microsoft account.
  </Step>
  <Step title="Launch Minecraft">
    Run `javli release 1.21.1` (or any version). JAVLI downloads the game, installs the required Java runtime automatically, and starts Minecraft.
  </Step>
  <Step title="Explore Further">
    Create instances, install modloaders, add mods from Modrinth, or spin up a local server — all from the same `javli` CLI.
  </Step>
</Steps>

<Note>
  JAVLI has only been extensively tested on Windows 64-bit. It may work on other platforms but behaviour is less thoroughly validated — please [report issues](https://github.com/Hampter588/JAVLI/issues) you encounter.
</Note>
